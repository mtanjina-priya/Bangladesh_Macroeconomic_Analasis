# Bangladesh_Macroeconomic_Analysis
## 📌 Project Overview
This project analyzes Bangladesh's macroeconomic indicators using Microsoft Excel and Power BI. The analysis focuses on unemployment, inflation, and GDP growth to identify trends and relationships over time.

## 🎯 Objectives
- Analyze unemployment, inflation, and GDP growth.
- Clean and prepare the dataset.
- Perform descriptive statistical analysis.
- Detect outliers using the IQR method.
- Examine correlations among variables.
- Build interactive visualizations using Power BI.

## 📂 Dataset
- Source: World Bank
- Country: Bangladesh
- Period: 1991–2024
- Variables:
  - Year
  - Unemployment
  - Inflation
  - GDP Growth

## 🧹 Data Cleaning
- Checked missing values
- Checked duplicate records
- Verified data types
- Prepared a cleaned dataset for analysis

## 📈 Excel Analysis
- Descriptive Statistics
- IQR Outlier Analysis
- Correlation Matrix
- Trend Charts
- Phillips Curve (Scatter Plot)

## 📊 Power BI Dashboard
The dashboard includes:
- KPI Cards
- Unemployment Trend
- Inflation Trend
- GDP Growth Trend
- Phillips Curve
- Year Slicer

## 🛠️ Tools Used
- Microsoft Excel
- Power BI
